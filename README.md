# DevOps Laboratory Works

Репозиторий создан для выполнения лабораторных работ и изучения основных DevOps-практик.

## Автор

## Контакты

## Цель проекта

Изучение инструментов и подходов DevOps, а также получение практических навыков работы с системами контроля версий, контейнеризацией, автоматизацией и CI/CD.

## План изучения DevOps

1. Git и GitHub
2. Основы Linux и командной строки
3. Docker и контейнеризация
4. Docker Compose
5. CI/CD
6. GitHub Actions
7. Основы Kubernetes
8. Infrastructure as Code
9. Мониторинг и логирование
