# Contribution Guidelines

## Общие правила

Все изменения проекта должны выполняться в отдельных ветках.

## Работа с ветками

Основные ветки проекта:

- `main` — стабильная версия проекта;
- `develop` — ветка разработки.

Для новых изменений рекомендуется создавать отдельную ветку от `develop`.

## Коммиты

Сообщения коммитов должны быть краткими и отражать суть внесённых изменений.

Примеры:

- `Add project documentation`
- `Update README`
- `Fix configuration`

## Pull Requests

Перед добавлением изменений в ветку `main` необходимо создать Pull Request.

В описании Pull Request необходимо указать:

- какие изменения были внесены;
- зачем они были внесены;
- какие файлы были изменены.

После проверки изменений Pull Request может быть объединён с основной веткой.
